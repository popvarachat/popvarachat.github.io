การตรวจ Pass · Fail · Hold · Reject

แยกผลการตรวจรายวัน ออกจากสถานะ Lot ล่าสุด การ Hold การ Reject และการอนุมัติปลด Hold อย่างชัดเจน

กำลังตรวจหลักฐาน QC...
จำนวนการตรวจ—Inspection Events
ตรวจผ่าน—Result: PASS
ไม่ผ่าน / Reject—Result: FAIL + NCR
Hold ที่ยังไม่ปลด—Current H inventory
ปลด Hold วันนี้—H → P approved event

QC Status & Decision Flow

ทุกเหตุการณ์ต้องเชื่อม Item/Lot/Document, Timestamp, ผู้ตรวจ และการรับรอง

รับล็อตReceipt / Lot
รอตรวจRequired Test
ผลตรวจPass / Fail
Hold (H)Hold reason
Reject / NCRDisposition
ReleaseH → P approval
H ไม่ได้แปลว่า Reject เสมอไป และ Test Result “N” ยังไม่ควรนับ Fail จนกว่าจะรู้เกณฑ์การตรวจและผล Disposition

แหล่ง ERP ที่ต้องตรวจ

  • P3711 / P553711Y: วันที่ตรวจ + Test Result Pass/Fail
  • P554108 / P4108: สถานะ Lot H/P และ Last Status Date
  • P3703 / P43250: Nonconforming, Reject, Disposition
  • Lot Audit: ประวัติ H → P พร้อมผู้อนุมัติ/เวลา
  • WO / TS / Control Plan: งานที่ถูกบล็อก + เจ้าภาพ
