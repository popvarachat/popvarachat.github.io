บทบาทตรวจสอบและลงนามรับรอง

Business Process Owner / Key User

ยืนยันว่า Flow, คำถาม Report, Parameter, ขั้นตอนจริง และผลลัพธ์ถูกต้อง รวมทั้งชี้กรณีผิดปกติ

ERP Admin / Functional Consultant

ยืนยัน P/R Object, Version, Processing Options, Data Selection, UBE Update Y/N และสิทธิ์หน้าจอ

ERP Developer / Data Steward

ยืนยัน Business View/Physical Table/Field/Business Key, Custom Logic และ Source Lineage

QC / Accounting / Store / Planning

ตรวจสอบผลกระทบข้ามฝ่าย เช่น HOLD, 9D/TS, Run99, Cost/WIP, Invoice และ GL

IT / Security / Architecture

รับรองอินเทอร์เฟซอ่านข้อมูล สิทธิ์ Service Account, Data Pool Security และ Data Quality

Executive / Human Gate

อนุมัติ Promise/OTD Policy, เจ้าของ KPI, การเปิดเผยข้อมูล และการยกระดับไปสู่ Write-back ในอนาคต

6 Gates ก่อนประกาศครบ 100%

A · UBE / Version Metadata

Processing Options, Data Selection, Data Sequencing สำหรับ Object สำคัญ

B · Business View / Table

รับรอง Physical Table lineage ของ Manufacturing และ Custom Objects

C · Update Y/N

แยก UBE รายงานอย่างเดียวจาก UBE ที่แก้ข้อมูล โดยห้าม Run เพื่อทดลอง

D · Status Governance

Current → Allowed Next State, Authority, Reversibility, Version

E · Promise / OTD

Management Human Gate: วันที่อ้างอิง, การเลื่อนนัด, Partial Delivery และ Cutoff

F · Read-only Integration

ตัดสิน AIS/Orchestrator/API, Governed DB View หรือ Scheduled Export พร้อม Security
