    01 / EXECUTIVE DECISION CENTER

    ผู้บริหารต้องตัดสินใจอะไรจาก CRM?

    CRM ไม่ใช่เพียงฐานชื่อลูกค้า แต่เป็นระบบที่เชื่อมโอกาสขาย การออกใบเสนอราคา การรับโครงการ การส่งต่อ ERP และการบริการหลังการขาย แต่ละตัวเลขต้องมีแหล่งข้อมูลและเกณฑ์ความเชื่อมั่น

    • ดู Deal Amount, Stage และ Probability

    • ตรวจ Approved Date / ERP Order Value
    • ต้อง reconcile จำนวนเงินก่อนใช้สรุป

    07 / OPERATING CONTROLS & RCA

    เจอข้อมูลผิด / ยอดไม่ตรง / งานค้าง ต้องแก้ที่ต้นเหตุ

    CAR-01: ERP Reference ว่าง หรือไม่ตรงกัน
    แยกสถานะเอกสารก่อน (ยังไม่อนุมัติ / ยังไม่ส่งต่อ / Sync Error) ตรวจจาก CRM DetailView แล้วเทียบ ERP ตามสิทธิ์ ค่อยสรุปสาเหตุ ไม่ตั้งสมมติฐานว่า Sync เสียทันที
    CAR-02: Quotation Report กับเอกสารจริงยอดไม่ตรง
    ตรวจช่วงวันที่ Quote Date, Option/Revision, ส่วนลดทั้งโครงการ, ภาษี และสูตรรวมเงิน จับคู่เลข Quote ก่อนเปรียบเทียบเงิน
    CAR-03: Project Pipeline หรืองานส่งมอบไม่อัปเดต
    ตรวจ Owner, Project Stage, ERP Order Value และข้อมูลส่งมอบ แยกปัญหาเป็น Data Entry / Integration / Process Delay ก่อนแก้
    CAR-04: รายงานมีผลกระทบจากการส่งอีเมล
    แยก Preview ที่ไม่มีผลภายนอกออกจาก RUNREPORT ซึ่งมีพารามิเตอร์ผู้รับ ต้องใช้ Controlled Test และหลักฐานผู้อนุมัติ
    CAR-05: สิทธิ์ผู้ใช้ไม่เหมาะสม
    ทำ Matrix ตาม Role · Module · Read/Create/Edit/Delete/Export ระหว่าง Sales, Service, Management และ Admin โดยใช้บัญชีที่ได้รับอนุญาต
