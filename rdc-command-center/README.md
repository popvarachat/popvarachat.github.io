# RDC Command Center

Public-safe GitHub Pages dashboard for the local RDC multi-agent execution platform.

## What it shows
- FAST EXECUTION MODE
- Agent / sub-agent role architecture
- Local skill playbook
- Lazy Global Arsenal metadata
- Weekly capability upgrades and global candidates
- Human Gate / provider status

## Public-safe rule
Do not publish credentials, tokens, email addresses, device IDs, internal IPs/hostnames, or secret file paths.

Live page: https://popvarachat.github.io/rdc-command-center/
