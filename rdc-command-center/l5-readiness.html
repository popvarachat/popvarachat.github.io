ลำดับแก้ไขที่แนะนำ

  1. ยืนยัน Dual Cloud Read/Write จากทั้งสอง Host และตรวจข้อมูลบริษัทไม่ไหลไป Google Drive ส่วนตัว
  2. ทำ Queue/Lease Authority ที่มี Atomic Claim แล้วทดสอบเชื่อม PC–NB จริง
  3. ทดสอบ Shutdown/Restart/Hotspot ด้วยงานจำลองและ Checkpoint จริง
  4. เชื่อม Orchestrator กับ Task Trace + QA ทุก Executor แล้วแสดงข้อมูลสดแทนทะเบียนคงที่
  5. รับรอง L5 หลังมีผลทดสอบและ Rollback ที่ทำซ้ำได้เท่านั้น

ขอบเขต: หน้าเว็บ Public-safe ไม่มีข้อมูลบัญชี อีเมลภายใน พาธส่วนตัว IP หรือหลักฐานดิบของบริษัท ข้อมูลนี้เป็น Snapshot ไม่ใช่ Live Dashboard
