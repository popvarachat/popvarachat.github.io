# Practika Network Diagram

Public-safe executive Network Diagram for Practika.

## Purpose
- Show enterprise network architecture on GitHub Pages
- Separate confirmed logical topology from discovery-pending physical layers
- Provide a management-friendly view without exposing internal infrastructure details

## Security
This public project intentionally does **not** publish:
- internal IP addresses or subnets
- server or domain-controller hostnames
- MAC addresses
- mapped file shares
- switch ports, credentials or management interfaces

The detailed evidence-based Network Digital Twin remains internal on the authorized notebook.
