1. แหล่งข้อมูลที่ใช้ตรวจ

ดึง CB จาก Private Pivot บน NB โดยอัตโนมัติ 1 ครั้งเมื่อเปิดเว็บ หากไม่เชื่อมต่อ สามารถเลือกไฟล์ pivot.json ได้ ข้อมูลจะประมวลผลใน Browser เท่านั้น

กำลังอ่าน Private Pivot…

ไม่ส่งข้อมูล LINE ไป GitHub / Cloudflare · ไม่โพสต์ตอบห้อง LINE · ไม่ใช้ข้อความที่ไม่พบมาตัดสินว่าผู้รับผิดชอบไม่ได้แจ้งจริง · LINE ที่นำเข้าเป็น Snapshot ณ วันที่ของไฟล์ ไม่ใช่สถานะ Live
