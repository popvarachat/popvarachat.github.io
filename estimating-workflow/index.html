Human Gate และผู้รับรอง

G00–G08 ก่อนเสนอราคา ส่วน G09 หลังส่งมอบ บทบาทเป็นข้อเสนอให้บริษัทแต่งตั้งผู้มีอำนาจจริง

G00รอรับรอง

รับไฟล์และตรึง Version

AI: อ่านทุกชีต รวมซ่อน ภาพ และสูตร ทำ hash และเก็บตำแหน่ง

คน: รับรองว่าไฟล์/ชีตใดใช้จริง และที่ใดเป็นประวัติ

HOLD: ไม่มีที่มา Version หรือเลือกชีตหลักไม่ได้

G01รอรับรอง

ยืนยันงานและสเปก

AI: เทียบชื่อไฟล์ หัวชีต รหัส รุ่น ขนาด จำนวน ผิววัสดุ

คน: เลือก job/spec revision ที่มีอำนาจใช้งาน

HOLD: รุ่น/จำนวน/หน่วย/วัสดุขัดแย้งหรือ keyซ้ำ

G02รอรับรอง

เลือก BOM และถอดปริมาณ

AI: เลือก template ที่รับรองแล้ว คิดพื้นที่/ความยาว/ขอบ/จำนวน/กระบวนการ

คน: รับรอง BOM และรายการ optional โดยแยก0/ว่าง/ไม่ใช้

HOLD: ชิ้นส่วนมีขนาดแต่จำนวนว่าง วัสดุแทนกัน หรือไม่ระบุใช้/ไม่ใช้

G03รอรับรอง

เลือกแหล่งราคาและเงื่อนไข

AI: เทียบ SKU/สเปก/หน่วย/วันที่/จำนวนกับหลักฐาน; อ่านรูปเป็น candidate

คน: เลือกแหล่งราคาที่ใช้ได้ ไม่ใช่ถูกที่สุดอัตโนมัติ

HOLD: หมดอายุ ไม่มีวันเริ่ม เงื่อนไขไม่ตรง ตัวเลขลายมือไม่ชัด หรือราคาขัดกัน

คน: รวมในราคา แยกคิด ไม่เกี่ยวข้อง หรือเงื่อนไขสำรวจเพิ่มเติม

HOLD: รายการหน้างานอาจมีผลราคา/สัญญา แต่ขอบเขตหรือผู้รับค่าใช้จ่ายไม่ชัด

คน: รับรองลำดับคิด markup/waste/escalation/round และหมวดต้นทุนที่ครอบคลุม

HOLD: ตัวคูณ3/2/4/0.52/1.53/1.57/2.22 ไม่ทราบความหมายหรือ effective scope

G04รอรับรอง

HOLD: ราคาเสนอเป็น manual หรือราคาปัจจุบัน/ฐานเทียบ/ต้นทุนครบยังไม่ยืนยัน

G09รอรับรอง

ส่งมอบงานและคืนข้อมูลเรียนรู้

คน: ตัดสินใจเข้าหน้างาน/แก้งาน/เปลี่ยนขอบเขต; การปรับกฎต้องกลับG05/G08

HOLD: งานส่งไม่ครบ เอกสารไม่ครบ พื้นที่ไม่พร้อม หรือ scopeเปลี่ยน

คำรับรองต้องมี: คำตอบ · เหตุผล · หลักฐาน · ผู้รับรอง · วันที่ · เวอร์ชัน · วันสิ้นอายุ
กระบวนการ Gate และข้อมูลส่งต่อของ Agent

กระบวนการ Gate ที่ใช้ทุกขั้น

  1. ตรวจข้อมูล หน่วย ความสัมพันธ์ และเงื่อนไขของขั้นนั้น
  2. ถ้าขาด/ขัดแย้ง/หมดอายุ/ผิดเงื่อนไข ให้ HOLD พร้อมไฟล์–ชีต–เซลล์หรือภาพหลักฐาน
  3. AI เสนอคำตอบและกรณีทดลองได้ โดยบันทึกเป็น PROPOSED ซึ่งไม่ปิด Gate
  4. คนตัดสินใจโดยบันทึกคำตอบ เหตุผล หลักฐาน ผู้รับรอง วันที่ เวอร์ชัน และวันสิ้นอายุ
  5. ถ้าคำตอบทำให้ต้องแก้ข้อมูล ให้คำนวณและตรวจฉบับใหม่ คำรับรองต้องตรงกับข้อมูลฉบับนั้น
  6. รับรองบาง Gate ไม่ถือว่ารับรองทั้งงาน และ Gate ครบแต่ประเด็น/เงื่อนไขที่จำเป็นยังค้างต้องคง HOLD

ข้อมูลที่ต้องส่งต่อแต่ละขั้นสำหรับ AI Agent

เป็นโครงข้อมูลที่เสนอสำหรับระบบอนาคตเพื่อรองรับการย้อนสูตรและ Gate:

งานและสเปกที่รับรอง (G00–G01)
  -> BOM: รายการ ปริมาณสุทธิ/หลังเผื่อ หน่วย applicability เซลล์ต้นทาง (G02)
  -> Rate: ราคาและหน่วยซื้อ อัตราต่อหน่วย หลักฐานผู้ขาย อายุ/เงื่อนไข (G03)
  -> Scope: รวม/แยก/ไม่เกี่ยวข้อง/รอยืนยัน และผู้รับผิดชอบ (G07)
  -> Rule: สินค้า/variant หมวด price_stage ตัวคูณ ปัด เวอร์ชัน/วันมีผล (G05)
  -> Calculation: สูตร Input -> Intermediate -> Output และข้อค้าง (G04)
  -> Commercial: ราคาที่เสนอ VAT ขอบเขต เครดิต อายุ เหตุผลปรับ (G06)
  -> Approval: ผู้มีอำนาจ หลักฐาน คำรับรองฉบับเดียวกัน (G08)
  -> Delivery feedback: QCC ผลงานจริงและข้อเสนอแก้กฎ (G09)

price_stage ต้องบอกว่ารายการเป็นทุน อัตรางานผลิต ราคาชิ้นส่วนที่คิดแล้ว หรือราคาเสนอ เพื่อป้องกันการใช้ตัวคูณซ้ำ ทุกคำรับรองผูกกับชุดข้อมูลและเวอร์ชันกฎ หากสิ่งเหล่านี้เปลี่ยนต้องตรวจ Gate ที่ได้รับผลกระทบอีกครั้ง
